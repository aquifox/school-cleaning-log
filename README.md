# 청소 기록 저장기

학생이 자신의 청소를 기록하고 친구가 평가하는 학교생활 웹앱입니다.

## 실행

GitHub Pages 주소로 접속하거나 index.html을 다운로드해 브라우저로 엽니다. 설치나 서버는 필요 없습니다.

## 기능별 테스트

| 기능 | 테스트 | 기대 결과 |
|---|---|---|
| 일자 기록 | 이름, 일자, 역할 입력 후 등록 | 목록에 표시 |
| 중복 방지 | 동일한 이름, 일자, 역할 재등록 | 중복 안내 |
| 타이머 | 기록 선택 후 청소 시작 | 7분 카운트다운 |
| 완료 기록 | 7분 경과 | 해당 기록이 7분 완료로 표시 |
| 동료 평가 | 다른 이름으로 별점 저장 | 평균과 평가자 수 표시 |
| 자기 평가 방지 | 청소한 학생과 같은 이름으로 평가 | 제한 안내 |
| 평가 수정 | 같은 평가자 이름으로 다시 저장 | 평가자 수 유지, 별점 수정 |
| 저장 유지 | 새로고침 | 기록, 평가, 진행 중 타이머 유지 |
| 패드 화면 | 세로/가로 방향으로 접속 | 화면 폭에 맞춰 카드 배치 |

## 저장 방식과 한계

localStorage를 사용하므로 같은 기기의 같은 브라우저에 저장됩니다. 기기 간 공유 및 사용자 인증 기능은 없습니다. 타이머는 실제 청소 여부를 검증하지 않습니다. 브라우저 데이터 삭제 시 기록이 사라집니다.

## 제작

생성형 AI를 활용해 구현했습니다. HTML, CSS, JavaScript만 사용하며 외부 라이브러리가 없습니다.
